## 🚀 Running a Project

Clone the repository:

```bash
git clone https://github.com/DevSidh/Project2026.git
cd Project2026
```

For individual projects, check their respective folders for instructions.

### Recommended: Virtual Environment

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Linux/macOS:

```bash
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

Install the required dependencies when a project provides a `requirements.txt`:

```bash
pip install -r requirements.txt
```

Then run the project:

```bash
python filename.py
```
